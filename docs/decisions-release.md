# Release decisions log

Decisions taken while building the release setup (`docs/release-plan.md`, approved 2026-11-21). Each entry: the decision, the reason, and the alternative not taken. Items left undone are marked **Not done**.

## Phase A: macOS and the extension

- **The version script edits text, not parsed JSON/TOML.** `scripts/set-version.mjs` adds `"version"` after a known key (`private` in `package.json`, `productName` in `tauri.conf.json`) and replaces the exact `0.0.0` placeholder elsewhere, so the files keep their layout and `Cargo.lock` still matches (`--locked` builds keep working). Every file is checked before any is written. Only the `ks-download-manager` entry in `Cargo.lock` changes; the internal `engine` crate keeps `0.0.0` (it is never published). Alternative: `cargo set-version` (a cargo-edit install) and `npm version` (rewrites the whole file).
- **No Chrome host manifest from `/Volumes/…` or `…/AppTranslocation/…`.** A path test, not a system call: these are the two places a first open from the DMG or from a quarantined Downloads copy runs from, and both disappear. Alternative: `SecTranslocateIsTranslocatedURL` (needs a new crate and `unsafe`).
- **Deno notices: standard texts for the 123 crates without a licence file (owner, C).** Texts come from SPDX `license-list-data` v3.29.0 (released 2026-09-16), fetched by commit `31ba1a50e5397e00a304dbadc76531740e89ee48` so they cannot change under the same name, and cached in `src-tauri/binaries/.cache/spdx/`. Each licence appears once, with the list of crates that declare it; an `X WITH Y` declaration adds both texts (Apache-2.0 and LLVM-exception). Ten texts cover all 123 crates (Apache-2.0, BSD-2-Clause, BSD-3-Clause, BSL-1.0, CC0-1.0, LGPL-2.1-or-later, LLVM-exception, MIT, Unlicense, Zlib). The notices file says twice that these come from the declared licence, not from the crate's own file, and that copyright placeholders are the template's. Correction to `docs/decisions-stage5.md` (Part 5 licences): no crate in Deno 2.9.8's lock file declares nothing; all 123 declare a licence. Still open from Stage 5: V8's and ICU's texts come from their `main` branches, not the exact versions Deno links. Alternative: fetch each crate's repository for its own file (not every crate has a usable repository link, and the tag naming varies).
